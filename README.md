# JS Practice — Практика JavaScript

Статичний сайт для практики JavaScript за програмою GoIT (модулі 1–8).
Зроблено так, щоб можна було зручно працювати в **VS Code** і дивитися результат + помилки в консолі браузера.

## Як користуватися

1. Клонуй репозиторій:
   ```bash
   git clone https://github.com/vladikmukhar-star/js-practice.git
   cd js-practice
   ```

2. Відкрий папку в VS Code.

3. Встанови розширення **Live Server** (рекомендовано) і запускай `index.html` через нього.
   Або просто відкривай HTML-файли в браузері.

4. Пиши свій код у відповідних файлах `.js` або прямо в `<script>` на сторінці.
   Дивись результат і помилки в **DevTools → Console** (`F12`).

## Структура

```
js-practice/
├── index.html          # Головна сторінка з навігацією
├── css/
│   └── style.css       # Спільні стилі
├── module-01/          # Основи та функції
├── module-02/          # Розгалуження і цикли
├── module-03/          # Масиви
├── module-04/          # Об'єкти
├── module-05/          # Перебираючі методи масивів
├── module-06/          # ООП та класи
├── module-07/          # DOM і події
├── module-08/          # Події + деструктуризація
└── (module-09 ... module-12 можна додати пізніше)
```

Кожен модуль має свою папку і `index.html`.
Всередині модулів можна додавати окремі сторінки під теми або завдання.
