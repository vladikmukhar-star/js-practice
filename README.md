# JS Practice

Практика з JavaScript для модулів 1–8 курсу GoIT Fullstack. Завдання у форматі технічного завдання: читаєш ТЗ, пишеш код сам, запускаєш і дивишся результат у консолі на сторінці.

## Що всередині

- Модуль 1: основи та функції
- Модуль 2: розгалуження і цикли
- Модуль 3: масиви
- Модуль 4: об'єкти
- Модуль 5: перебираючі методи масивів
- Модуль 6: ООП та класи
- Модуль 7: DOM і події
- Модуль 8: деструктуризація, rest/spread, події (спливання, делегування)

У кожній темі: коротка «Суть» з прикладом, три завдання (легке, середнє, складніше), під кожним приклад такого ж формату. В кінці модуля підсумкові задачі, а в модулі 8 ще й фінальні завдання з усіх тем.

## Як запустити

1. Склонуй репозиторій: `git clone https://github.com/vladikmukhar-star/js-practice.git`
2. Відкрий папку у VS Code і запусти `index.html` через розширення Live Server (адреса `http://127.0.0.1:5500`). Напряму з файлу (`file://`) не працюватиме.
3. Обери модуль, пиши код у редакторі під завданням, натискай «Запустити».

## Як користуватись

- Пиши код сам, без ШІ. Нехай буде помилка, це нормально.
- Код, передбачення й галочка «Зроблено» зберігаються в твоєму браузері (localStorage) і не потрапляють на сервер.
- Поле «Моє передбачення» необов'язкове: корисне там, де код уже дано і треба передбачити результат.
- У модулях 7–8 над консоллю є справжня сторінка: клікай по ній, і результати подій з'являться в консолі.
- Нескінченний цикл зупиниться автоматично через 3 секунди.

## Структура

- `index.html` — головна
- `module.html?m=N` — сторінка модуля (одна на всі)
- `js/app.js` — редактор, запуск коду, збереження
- `data/module-N.json` — завдання модуля
- `demos/` — маленькі демо-проєкти (лічильник, модалка, слайдер, форма)
